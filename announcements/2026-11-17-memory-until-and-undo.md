# Paměť s datem konce a zpět k předchozí verzi
Když Moneypenny řeknete něco jen na čas („do pátku jsem ve Vídni“, „tento týden beru antibiotika“), zapamatuje si to s datem konce. Po tom dni si to přestane pamatovat a vzpomínka se přesune mezi nedávno smazané, odkud ji můžete vrátit.

**Co dalšího**
- **Předchozí verze vzpomínky:** když Moneypenny vzpomínku přepíše nebo sloučí a ztratí se přitom nějaký detail, v sekci Data u ní klepněte na ikonu historie a vraťte předchozí znění.

# Memories with an end date, and undo for the last change
When you tell Moneypenny something that only holds for a while ("I'm in Vienna until Friday", "on antibiotics this week"), it remembers it with an end date. After that day it stops using it, and the memory moves to Recently deleted, where you can restore it.

**Also**
- **A memory's previous version:** if Moneypenny rewrites or merges a memory and a detail gets lost, tap the history icon next to it on the Data page to put the earlier text back.
