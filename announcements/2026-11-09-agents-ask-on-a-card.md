# Agenti se ptají na stejné kartě
Když agent potřebuje váš souhlas, ukáže vám teď přesně tu změnu, kterou chce udělat.

**Co je nového**
- **Přesně to, co uvidíte.** Na kartě je konkrétní úkol, událost nebo trénink. Po schválení agent udělá jen tohle – nic jiného.
- **Odpovědět můžete i napsáním.** V chatu agenta stačí napsat „ano“ nebo „ne“. Agent pak rovnou pokračuje, nebo skončí.
- **Chat zůstává otevřený.** I když agent čeká, můžete se ho na cokoli zeptat; karta počká.
- **Dáme vědět, jak to dopadlo.** Po vaší odpovědi agent pokračuje sám a jeho zprávu dostanete jako notifikaci – v aplikaci čekat nemusíte.
- **V sekci Agents nahoře** najdete všechno, co čeká na vás, se stejnými kartami.

# Agents ask on the same card
When an agent needs your OK, it now shows you exactly the change it wants to make.

**What's new**
- **Exactly what you see.** The card shows the actual task, event or workout. Once you approve, the agent does that and nothing else.
- **Answer by typing, too.** In the agent's chat, just reply "yes" or "no". The agent carries on, or stops.
- **The chat stays open.** While the agent waits, you can ask it anything; the card waits.
- **You'll hear how it went.** After you answer, the agent carries on by itself and its report arrives as a notification - no need to wait in the app.
- **At the top of Agents** you'll find everything waiting for you, with the same cards.
