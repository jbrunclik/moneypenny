# Prohlížeč umí víc
Když asistent prochází web za vás, umí teď stisknout klávesu (třeba Enter ve vyhledávání bez tlačítka), vybrat položku z rozbalovacího seznamu a stáhnout soubor, který stránka nabízí – vstupenku v PDF, trasu GPX nebo export do CSV. Stažený soubor najdete přiložený v odpovědi.

<!-- lang: en -->
# The browser can do more
When the assistant browses a site for you, it can now press a key (like Enter in a search box with no button), pick from a dropdown list, and download a file the page offers - a ticket PDF, a GPX route or a CSV export. The downloaded file comes attached to the reply.
