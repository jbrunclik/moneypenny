# Úprava zprávy s přílohou
Zprávu s fotkou nebo souborem teď můžete upravit stejně jako jakoukoli jinou: změní se jen text, příloha zůstane a Moneypenny odpoví znovu.

<!-- lang: en -->
# Edit a message that has an attachment
A message with a photo or file can now be edited like any other: only the text changes, the attachment stays, and Moneypenny answers again.
